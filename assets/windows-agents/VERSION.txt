Server 2012 notes fixed in this build:
- No Bun EXE (ClosePseudoConsole)
- Config uses hand-built JSON (no ConvertTo-Json nested "bad form")
- Metrics use JavaScriptSerializer (no PS3 array value/Count wrap)
- No double-quoted regex with backslash-paren
- ASCII-only script text
- Config round-trip verified before sync starts
- Drive-sync installer preserves config.json on upgrade (Setup only if missing)
- Script path resolved via PSCommandPath (safe inside functions)
- Config JSON built by concatenation (passwords with { } safe; no -f)
- PULL ONLY: Assert-PullOnlyPaths + robocopy SOURCE->LOCAL; /PURGE is local-only
- Destination must be local disk DriveType 2/3 (rejects network-mapped letters)
- Quiet robocopy logging: heartbeats + copy issue lines + end summary
- Shared machine tag at %ProgramData%\HammerByte\.server-tag
- Agent payload types: ping (60s alive), metrics (long interval), drive_sync (sync utility)
- Metrics include desktop JPEG screenshot (best-effort; may be blank under SYSTEM)
- Temperature max computed without Measure-Object on hashtables (PS3/4 safe)
- Temperature zones stay as hashtables (not PSObject) so JavaScriptSerializer works
- Supervisor backs off when antivirus blocks agent.ps1 instead of spinning
- Installers + supervisor/drive-sync add Windows Defender ExclusionPath for
  %ProgramData%\HammerByte (and Unblock-File) so scripts are not quarantined

On child after deploy: unzip package, run .cmd as Administrator once.
